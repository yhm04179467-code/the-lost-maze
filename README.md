THE LOST MAZE - Final Project

Files:
- maze.py : main Python game
- maze_history.txt      : created automatically after playing

Requirements:
- Python 3
- No external libraries are required.

How to run:
1. Open Terminal / Command Prompt in this folder.
2. Run:

   python maze.py

Controls:
- W = Up
- S = Down
- A = Left
- D = Right
- Q = Quit

Symbols:
- P = Player
- # = Wall
- K = Key
- T = Trap
- $ = Treasure
- E = Exit

Game Features:
- 3 maze levels
- Player health
- Score system
- Step counter
- Keys and locked exits
- Random trap damage
- Treasure
- Game history saved to a text file
- Main menu and instructions
